# 메모플러스 (Memo+)

**메모를 더 편리하게.** Windows 스티커 메모를 분석해서 다시 만든 데스크톱 메모 프로그램입니다. Java Swing으로 만들었습니다.

> 1.0.x까지는 이름이 QuickMemo였습니다. 1.1.0부터 메모플러스(MemoPlus)로 바뀌었고, 메모·설정은 처음 실행할 때 새 폴더로 그대로 옮겨집니다.

## 설치

1. [Releases](https://github.com/kkangji99/MemoPlus/releases/latest)에서 `MemoPlus-x.y.z-windows-x64.zip`을 받습니다.
2. 원하는 폴더에 압축을 풉니다. 바탕화면이나 문서 폴더처럼 **쓰기 권한이 있는 곳**에 풀어야 합니다(Program Files는 안 됨).
3. `MemoPlus\MemoPlus.exe`를 실행합니다. 자바 런타임이 함께 들어 있어서 Java를 따로 설치할 필요가 없습니다.
4. 설정 → 정보 → **이 PC에 설치**를 누르면 `%LOCALAPPDATA%\Programs\MemoPlus`로 옮기고 시작 메뉴·앱 목록에 등록합니다. 제거는 Windows 설정의 앱 목록에서 합니다(메모는 남습니다).

## 자동 업데이트

프로그램을 실행하면 이 저장소의 최신 릴리스를 확인합니다. 더 새 버전이 있으면 내려받아 설치 폴더를 바꾼 뒤 다시 실행합니다. 켜 둔 채로 있어도 6시간마다 확인해서 알려 줍니다.

- 받은 파일은 GitHub가 알려 주는 SHA-256과 맞는지 확인한 뒤에만 설치합니다.
- 메모는 `%APPDATA%\MemoPlus`에 저장되므로 업데이트해도 그대로 남습니다.
- 네트워크가 없거나 실패하면 지금 버전으로 그냥 실행합니다. 기록은 `%APPDATA%\MemoPlus\update.log`에 남습니다.

## 기능

메모 목록 위쪽의 **ⓘ 버튼**을 누르면 앱 안에서 사용설명서를 볼 수 있습니다. 설정과 사용설명서는 위쪽 찾기 칸(Ctrl+F)으로 항목을 바로 찾을 수 있습니다.

- 디자인 7가지: 심플(기본) / 아기자기 / 크리스마스 / 봄 / 여름 / 가을 / 겨울, **추천 디자인으로 변경**(새 디자인·계절에 맞춰 자동)
- 밝게 / 어둡게 / 시스템(Windows 설정 따라가기), 글자 크기
- 메모 창 여러 개, 색 7가지, 창 위치·크기 기억
- 스티커 모양: 사각(기본), 동그라미, 하트, 별, 구름, 말풍선 (메모의 `…` 메뉴에서 변경)
- 굵게(Ctrl+B), 기울임(Ctrl+I), 밑줄(Ctrl+U), 취소선(Ctrl+T), 글머리 기호(Ctrl+Shift+L), 할 일 목록(Ctrl+Shift+C)
- 글머리 기호·할 일 목록 들여쓰기: Tab / Shift+Tab
- 이미지 붙여넣기(Ctrl+V), 파일 끌어놓기, 이미지 버튼
- 링크: http 주소에 밑줄, Ctrl+클릭으로 열기
- 메모 목록: 검색(찾은 글자 강조), 썸네일, 즐겨찾기(위쪽 고정), 끌어서 순서 변경, 여러 개 골라 지우기
- 휴지통(30일 보관)과 되돌리기
- 메모 잠금(AES-256-GCM 암호화, 키는 Windows DPAPI로 보호)
- 알림: 정한 시각에 메모를 앞으로 띄우기
- 자동 백업(하루 한 번, 최근 7개), 내보내기·가져오기
- 알림 영역 아이콘, Windows 시작 시 실행, 어디서든 새 메모(Ctrl+Alt+M)
- Windows 스티커 메모 가져오기
- 윈도우 검색에서 `memo` / `메모`로 실행 (exe 실행 시 시작 메뉴에 자동 등록)

## 개발

JDK 21 이상이 필요합니다.

```bat
build.bat          :: MemoPlus.jar 빌드
run.bat            :: jar 실행 (자동 업데이트 꺼짐)
```

## 릴리스

1. `src\MemoPlus.java`에서 `VERSION`을 올립니다(예: `1.1.1`).
2. `release.ps1`을 실행하면 `dist\MemoPlus-<버전>-windows-x64.zip`이 만들어집니다.
3. GitHub에서 태그가 `v<버전>`인 릴리스를 만들고 zip을 첨부합니다. gh CLI가 있으면 `release.ps1 -Publish`로 한 번에 할 수 있습니다.

릴리스의 zip 이름은 반드시 `-windows-x64.zip`으로 끝나야 자동 업데이트가 찾습니다. zip에는 1.0.x(QuickMemo)의 업데이터가 찾는 `QuickMemo.exe`도 같은 앱을 띄우는 실행 파일로 함께 들어갑니다.

> 1.0.0 빌드는 업데이트 적용 버그가 있어 자동 업데이트되지 않습니다. 1.0.0을 쓰고 있다면 최신 릴리스를 받아 다시 설치해 주세요.
